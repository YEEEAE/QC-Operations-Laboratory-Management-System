# Skill Routing Protocol

Before starting any task:

1. Inspect the available Cline Skills.
2. Determine which skills are relevant to the user's request.
3. Activate every relevant skill before planning or modifying files.
4. Follow the activated SKILL.md instructions throughout the task.
5. If multiple skills are relevant, use all necessary skills rather than choosing only one.
6. Do not ignore a relevant skill merely because the task appears simple.
7. Load supporting skill resources only when needed to avoid unnecessary context usage.

Skill selection must be based on the task requirements and each skill's description.

For complex tasks, architecture work, audits, debugging, database work, UI/UX,
security, testing, deployment, or code review, actively check for specialized
skills before proceeding.
