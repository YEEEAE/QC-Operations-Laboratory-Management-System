# AI Visibility

Use this skill for LLM mention research, AI search visibility, brand citation analysis, or Generative Engine Optimization (GEO) for BRIGHTAI.

## Measurement workflow

1. Define the brand, canonical domain, Saudi market, language, platforms, date window, and competitor set.
2. Use DataForSEO LLM mention endpoints when available. Record platform, keyword, search scope, location/language, timestamp, raw metrics, normalized score, and source.
3. Test a repeatable prompt set across discovery, category, solution, local, trust, and comparison questions. Keep prompts stable between measurement periods.
4. Classify each result: mentioned/not mentioned, recommended/not recommended, citation present/absent, factual accuracy, competitor displacement, and sentiment/positioning.
5. Separate measured API data from model-observation samples. Do not present a small prompt sample as market share.
6. Convert gaps into fixes: entity clarity, author/expert proof, direct answers, structured data, evidence, internal links, crawlability, and fresh Saudi use cases.

## Output

Provide an executive scorecard, query-level evidence, competitor comparison, prioritized actions, and a retest schedule. Include limitations and confidence. Never fabricate mentions, rankings, citations, or API values.

## Privacy and safety

Do not send secrets, private customer data, or unpublished sensitive material to an external model or API. Use only public site content unless the user explicitly authorizes otherwise.
