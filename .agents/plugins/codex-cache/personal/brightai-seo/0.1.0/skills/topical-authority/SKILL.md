# Topical Authority

Use this skill to turn Saudi keyword and SEO evidence into an editorial architecture that compounds over time.

## Method

1. Establish the entity: BRIGHTAI is a Saudi AI and automation platform serving businesses, entrepreneurs, and government teams.
2. Define 3–7 topic pillars tied to real services and buyer problems, not vanity keywords.
3. Build clusters with one canonical pillar, supporting guides, comparison/use-case pages, local variants, and FAQ coverage.
4. For each page specify primary query, secondary queries, intent, audience, funnel stage, target URL, required evidence, author/expert, publish/update dates, and CTA.
5. Create internal-link rules: child pages link to the pillar, sibling pages link where useful, and every page has a next step without creating circular or forced links.
6. Prioritize gaps using Saudi demand, commercial fit, authority potential, freshness, and effort. State assumptions when metrics are unavailable.
7. Include GEO requirements: direct 40–60-word answer, question-shaped headings, quotable definitions, verifiable sources, clear entities, and localized examples.

## Deliverables

Return a topical map, page briefs, internal-link map, 30/60/90-day sequence, and measurement plan. Avoid thin doorway pages, duplicate city pages, unsupported statistics, and content cannibalization. Keep Arabic content in simplified formal Arabic with a light Saudi context; use English only where the page strategy requires it.
