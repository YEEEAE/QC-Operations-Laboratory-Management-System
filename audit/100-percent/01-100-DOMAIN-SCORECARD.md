# QC-100-01 — 100-Domain Scorecard

## Scoring method

Each row uses five evidence dimensions in this order: **I/T/R/D/S** = implementation, automated test, runtime/UAT, documentation, security evidence.

- `1` = current direct evidence exists for the applicable requirement.
- `0.5` = partial, static, indirect, or scope-limited evidence.
- `0` = missing, blocked, contradictory, or not applicable evidence not established.
- **Score** = rounded average of the five values × 100.
- `UNVERIFIED` overrides the numeric score when runtime/UAT evidence is required but absent.
- `FAIL` is used when current source inspection found a contradictory defect or a required control is demonstrably failing.
- No row is closure-level. The score is a baseline, not a completion percentage.

Evidence references are defined in `00-REALITY-FREEZE.md`; remediation IDs are defined in `02-GAP-REGISTER.md`.
