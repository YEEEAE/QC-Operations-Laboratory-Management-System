# Regulated UX writing audit — 2026-09-10

## Scope

Reviewed user-facing copy in navigation, shell, shared feedback/form/data/governance components, and route families for Tasks, Quality, Quarantine, Laboratory, Assets, Documents/Governance, System Health, Backup/Restore, AI Advisory, Search, Notifications, Reports, Permissions, and Audit history.

## Copy decisions

| Surface | Use | Avoid | Reason |
| --- | --- | --- | --- |
| Navigation | `Audit history`, `System health`, `Backup and recovery`, `AI advisory` | Bare internal nouns or unexplained codes | Names the operator's destination and preserves domain terms. |
| Actions | `Create task`, `Submit for review`, `Approve document`, `Reject inspection`, `Release item`, `Record restore request` | `Submit`, `Process`, `Confirm`, `Continue` | States the intended operational outcome. |
| Empty | `No records in this view` / `No records match the selected filters` | `No data` / `Nothing here` | Distinguishes a real empty result from unavailable data and filter mismatch. |
| Unavailable | `The system did not receive a confirmed response...` | `0`, `No records`, or reassuring success copy | Provider failure is not zero records. |
| Backup | `Backup created` and `Restore verified` are separate facts | One combined green status | Creation/verification of an artifact is not restore proof. |
| Laboratory/Quarantine | `PASS` and `RELEASED` remain separate | Treating PASS as release | Preserves controlled business semantics. |
| AI | `AI output is advisory only` | `Approved`, `decision`, `pass`, `release` | AI cannot exercise controlled authority. |
| Audit | Human labels for filters; technical IDs remain values | `Subject type`, `Actor id`, `Request` as primary labels | Helps operators filter by business meaning while preserving traceability. |

## Required vocabulary

The canonical reusable dictionary is `src/shared/copy/ux-vocabulary.ts`. Regulated terms were not renamed; only surrounding presentation copy was normalized.

## Findings

- Generic action labels were replaced in shared components and high-risk pages where the action is known.
- Provider-unavailable states explicitly withhold counts and do not present an empty/zero state.
- Backup and restore wording keeps artifact status separate from restore verification.
- AI copy explicitly limits output to advisory use and copy/draft actions.
- Error copy includes a specific recovery path and preserves the user's input where the route supports it.

## Remaining evidence boundary

Static copy review cannot prove every runtime notification generated by database/outbox producers uses this vocabulary. Notification producer content, authenticated role visibility, and browser-rendered copy still need live fixtures before a complete runtime claim.
