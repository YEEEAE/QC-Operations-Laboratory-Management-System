# CA-05 — القرارات البصرية الثابتة لبقية الصفحات

قائمة مُطبَّقة على pilots الخمسة ومقيسة، تُلزم بها بقية الشاشات عند فتحها.
كل قيمة هنا **مقاسة على المرشّح** (HEAD `b7853437` + إصلاحين مشتركين)؛ ما ليس منها
مرجعًا مُثبَّتًا فهو مشتق ومُعلَّم.

## 1. القشرة (تطابق المرجع A — لا تعديل)

- `html[data-visual-direction='capa-a']` على عنصر `html` (لا على `.app-shell`).
- canvas `#14181E` / panel `#252B34` / text `#E8EDF5` / muted `#9BA3AF` /
  accent `#92B8F2` / accent-hover `#A6C5F5` / border `#383F4C` / warning `#D5A36F`.
- Sidebar **كما هو**: نفس البنية والترتيب والأيقونات والروابط (32 رابطًا في 10 أقسام)
  ونفس الألوان `#111d2d` / `#f2f6f9` / `#5dd0d7` ونفس مرشّحات الصلاحيات ونفس السلوك.
  عرضه 264px عند ≥768px، ويتحول إلى درج ثابت ≤760px (`min(86vw, 20rem)`).
  **لا تُنسخ المساحة الفارغة 264px من الاستكشاف إلى المحتوى** — 264px هو عرض عمود
  الشريط نفسه، ومحتوى الصفحة يبدأ بعده.
- أي تعديل في التنقل قرار منتج مستقل، خارج هذا التسليم.

## 2. قواعد المحتوى (مقيسة على pilots)

1. **أرضية 44px لكل هدف تفاعلي** في `#main-content`: أزرار، روابط، `summary`,
   مدخلات، محددات — بما فيها زر الفلاتر ومحدد «Row density» (أصلحنا الاثنين في
   `FilterBar.astro` و`DataTable.astro`).
2. **لا نص تحت 12px**؛ التوزيع المعتمد: 12px (بيانات/تسمية)، 13px (متن مت microscop)،
   14–17px (عناصر وبيانات تفاعلية)، 20–24px (عناوين)، 28px (أرقام لوحات فقط).
3. **الأزرار ذات خلفية accent تأخذ `var(--text-on-accent)`** ولا يعيد 링크 عام
   تلوينها. القاعدة العامة داخل `.app-main` تخصّ الروابط النصية فقط؛ روابط الأزرار
   مستثناة بأسمائها (`button`, `link-button`, `start`, `action`, `primary`,
   `secondary`, `controlled`, `print-report`, `empty-action`).
4. **تباين ≥ 4.5:1** للنص العادي و≥ 3:1 للحدود؛ الأزواج المرجعية المعتمدة:
   `text/panel 12.12:1`، `muted/panel 5.60:1`، `muted/inset 5.08:1`،
   `accent/inverse 8.79:1`، `focus 7.03:1`، `control-border 3.29:1`.
5. **حلقة تركيز 2px** مرئية على كل محطة تركيز (14/14 في كل صفحة).
6. **الأرقام `tabular-nums`** في الجداول والتواريخ والكميات.
7. **العناوين والأفعال sentence case**، الواجهة English/LTR.

## 3. تكييف العرض بحسب نوع الصفحة

| النوع | القاعدة |
| --- | --- |
| لوحة (dashboard) | بطاقات مؤشرات + قائمة انتباه + سلسلة زمنية؛ كل عدّاد له مصدر ورابط؛ `null` = «Not available» لا صفر |
| سجل (register) | `FilterBar` + `AppliedFilters` + `DataTable` + `Pagination`؛ فصل EMPTY عن FILTERED EMPTY؛ «Not applied» لقيمة فلتر مرفوضة بدل تجاهلها |
| نموذج (form) | عمود واحد ≤768px، عمودان ≥960px؛ ملخص قبل الحفظ؛ خطأ مُجمَّع أعلى الحقول + `aria-invalid`؛ المسار الأصلي POST حقيقي والمسار المحسّن تحسين فقط |
| تفاصيل (record) | عمود قراءة واحد + لوحة إجراءات جانبية (تنهار إلى عمود واحد ≤820px)؛ الحالات المنفصلة (Receiving / Inspection / Release) تبقى ثلاث قيم مستقلة |
| قرار محجوب | بطاقة مركزية بعرض 720px، padding 32px، هوية القرار ومالكها ونص «لم يُغيَّر شيء» — بلا نموذج بديل |

## 4. آلة الحالات التي تُعرض كما هي (لا تُستبدل)

`AUTHORIZATION` (لا صلاحية) ≠ `PROVIDER_UNAVAILABLE` (انقطاع) ≠ `EMPTY` (لا سجلات)
≠ `FILTERED EMPTY` ≠ صفر رقمي. كل حالة لها نصها الخاص، والانقطاع لا يتحول إلى
صفوف فارغة ولا أصفار. `PASS` لا يعني `RELEASED`، و`Inspection Result` منفصل عن
`Release System State`.

## 5. ما لا يجوز في بقية الصفحات

- لا إضافة KPI أو دور أو عتبة أو حالة امتثال غير موجودة في مصدر؛ لا أرقام مصنّعة.
- لا تغيير Sidebar (بنية/مظهر/روابط/ترتيب/أيقونات/صلاحيات/سلوك).
- لا تغيير schema أو API أو قواعد الأعمال أو السياسة خارج CA-F-*.
- لا تغيير مسار POST الأصلي أو idempotency أو سياسة التوقيع.
- لا ادعاء أداء أو WCAG AA أو UAT أو إفراج على أساس هذه البوابة.
