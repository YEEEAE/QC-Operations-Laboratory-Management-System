02 / Method

كيف حُسبت النسب؟

لئلا تتحول النسبة إلى انطباع مبهم، كل صف يُقرأ على خمس عدسات متساوية.

  1. 20 نقطة مصدر متطلبات أو سياسة واضحة.
  2. 20 نقطة تنفيذ يمكن تتبعه في الكود.
  3. 20 نقطة رفض وحالات حدية وسلامة بيانات.
  4. 20 نقطة تحقق آلي حديث على النسخة ذات الصلة.
  5. 20 نقطة تشغيل حي أو قبول بشري/تشغيلي مناسب.

درجة كل مجال حكم تحليلي موزون ضمن هذه العدسات، لا ناتج أداة تغطية. المتوسط الحسابي لمئة مجال يعطي مؤشر التقرير. الغياب أو تعذّر الاختبار يخفض الثقة ولا يتحول إلى PASS. الفحوص المحلية رُكضت على Node 24.20.0؛ صفحات الإنتاج قُرئت دون تعديل بيانات. لم يُشغّل PostgreSQL أو E2E لأن Docker daemon غير متاح. لم تُفحص جميع تفرعات كل ملف يدويًا؛ الجرد شمل بنية المستودع وقراءات ممثلة لكل مجال.

06 / Free-license integrations

تكاملات مفيدة بلا اشتراك مدفوع

الخيارات أدناه مجانية الترخيص أو تُنفّذ بأدوات المشروع الحالية. تشغيل خدمة منفصلة قد يستهلك خادمًا وتخزينًا ووقت صيانة؛ لا يُعرض ذلك على أنه مجاني بالكامل. لا تفعيل أو نقل بيانات دون اعتماد مالك النظام.

01 / OBSERVABILITY

OpenTelemetry + Prometheus + Alertmanager

اجمع القياسات محليًا، واضبط تنبيهات outbox lag وschema readiness دون منصة مراقبة باشتراك. OpenTelemetry Collector · ترخيص Prometheus.

ترخيص مجاني؛ يلزم تشغيل وتخزين محليان، ووسيلة إيصال تنبيه متاحة. اعتماد العتبات والاحتفاظ مطلوب.
02 / IDENTITY

Keycloak مستضاف ذاتيًا عند الحاجة فقط

خيار OIDC مفتوح المصدر إذا احتاج النظام دخولًا مؤسسيًا؛ تبقى صلاحيات QC والنطاق وSoD داخل التطبيق. لا تضف خادم هوية إذا كانت المصادقة الحالية كافية. ترخيص Keycloak.

لا رسوم ترخيص؛ الاستضافة والإدارة والنسخ الاحتياطي للهوية لها تكلفة تشغيل. قرار المالك مطلوب قبل الربط.
03 / FILE GATE

ClamAV كخدمة فحص مستقلة

افحص الملفات في عملية/خدمة منفصلة قبل اعتمادها، مع MIME allowlist وحجر ورفض fail-closed؛ لا تدمج libclamav مباشرة دون مراجعة التزامات ترخيصها. ترخيص ومتطلبات ClamAV.

البرنامج مجاني؛ يحتاج ذاكرة وتحديث تواقيع ومساحة تخزين. سياسة الأنواع والحجم والاحتفاظ ما زالت قرار مالك.
04 / RECOVERY

PostgreSQL WAL + نسخ الملفات بأدوات موجودة

استخدم ميزات PostgreSQL المفتوحة وscripts/recovery الحالية لتمرين استعادة معزول مع manifest وhashes، دون شراء منتج نسخ جديد. ترخيص PostgreSQL · توثيق WAL/PITR.

لا رسوم برنامج؛ مساحة النسخ وبيئة التمرين قد تكون مدفوعة. RPO/RTO وretention لا تُفترض قبل اعتمادها.
05 / INSTRUMENT INGEST

استيراد ملفات الأجهزة داخل التطبيق

ابدأ بملف CSV/JSON مُعتمد من الجهاز، مع schema version وhash وتاريخ ومعرّف آلة ومعايرة وdedupe ورفض قياس بلا مصدر؛ استخدم parser واختبارات المشروع بدل منصة تكامل مدفوعة. لا تعتبر PASS صادرًا من الجهاز قرار QC.

لا اشتراك جديد؛ التكلفة هي التطوير والتحقق. نوع الجهاز والبروتوكول والمصدر العلمي تحتاج قرار مالك.
06 / RELEASE EVIDENCE

تقارير CI الحالية + استقبال خادمي موثوق

استخدم workflows والاختبارات الموجودة لإنتاج أدلة SHA وrun ID وartifact digest، ثم ingest خادمي يرفض stale/skip/mismatch. لا تضف خدمة تدقيق مدفوعة. حدود استخدام GitHub Actions.

لا خدمة مدفوعة جديدة؛ دقائق CI قد تتجاوز الحصة المجانية حسب الخطة، أو تتحمل تكلفة جهاز runner ذاتي.
07 / Execution prompts

برومبتات جاهزة للعمل المنضبط

كل برومبت محصور بمخرج قابل للتحقق. ابدأ بإصلاح بوابات المرشح، ثم نفّذ المعالجات التي تملك مصدرًا واختبار قبول.

01 — إصلاح بوابات المرشح

على HEAD الحالي، أصلح خطأ offset في مختبر tests، وانتهاك import في performance-metrics، وأخطاء lint التسعة، ثم صنف إخفاقات unit الخمسة عشر إلى اختلاف تنفيذ أو عقد قديم. لا تغيّر صلاحيات أو قواعد علمية. شغّل typecheck/lint/architecture/unit وأظهر نتائج النسخة النهائية.

02 — مطابقة recovery targets

قارن BACKUP-RECOVERY-PLAN مع recovery-metrics وشاشة backups. أزل أي عرض لقيمة RPO/RTO على أنها معتمدة ما دام القرار POLICY-DEPENDENT؛ اعرض UNKNOWN وسببها. لا تشغل نسخًا أو استعادة إنتاجية. تحقق من UI والعقود.

03 — مرصد واستعادة

صل OTLP collector ووجهة اختبار، اعرض exporter/alert delivery truthfully، ونفذ restore drill معزولًا للقاعدة والملفات. لا تفترض RPO/RTO؛ اطلب قرار المالك ثم احسب القياس الفعلي من evidence.

04 — التكاملات الآمنة

صمم عقود OIDC وinstrument ingest وtrusted CI evidence وfile scanner كواجهات منفصلة: actor/source/version/idempotency/audit/fail-closed. اكتب threat model واختبارات رفض قبل التفعيل. لا تربط مزودًا أو ترسل بيانات دون اعتماد مالك المجال.
