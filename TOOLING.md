# Tooling map

- `workspace-map/TOOLING.md` — complete file-by-file inventory for agent tools and remaining root files.
- `AGENTS.md` — project instructions and the area router list.
- `.agents/AGENTS.md` — agent-specific instructions.
- `.agents/mind/01-mind-latest.md` — current project state and decisions.
- `.agents/skills/` — project-local skills and their supporting files.
- `.agents/plugins/` — project-local plugin metadata.
- `.opencode/` — OpenCode configuration and skills.
- `scripts/diagnostics/generate-workspace-map.py` — regenerates the detailed inventories; use `--check` to detect stale lists.
